# 群聊 AI · 多模型对话客户端

一个不用安装、双击就能开的网页版 AI 客户端。支持单聊、多模型群聊、插件。

- **单聊**：选一个模型，直接问答，流式输出，随时点「停止」
- **群聊**：拉 2~4 个模型进一个会话，指定一个群主，群主主持讨论并给结论
- **插件**：本地安装，能扩展导出、统计等命令
- **会话管理**：改名（双击标题）、搜索、单个删除、一键清空
- **参数面板**：思考强度 / 温度 / 最大输出 / 群聊轮数 / 上下文估算与花费粗估

## 怎么跑

需要 Node.js（18 以上）。

```bash
node server.mjs
```

然后打开 http://127.0.0.1:7801

换端口：`node server.mjs 7802`

**不要直接双击 index.html**，浏览器会拦跨域请求，必须走这个小服务器。

## 怎么配模型

点右上「参数」旁边的齿轮，或者首次打开时的「打开设置」：

1. 选一个提供商（DeepSeek / 千问 / Kimi / GLM / OpenAI / Anthropic / Gemini / Groq / OpenRouter）
2. 点「加一个」，地址和模型名会自动填好
3. 只剩填 API 密钥这一个框
4. 点这一行的「测试」确认能通（填错会直接告诉你哪不对）
5. 关掉弹窗，直接说话

支持两类接口协议：OpenAI 兼容（绝大多数）和 Anthropic 原生。

## 密钥存在哪

**只存在你这台电脑的浏览器 localStorage 里，不上传任何服务器。** 代码里没有任何硬编码密钥。

带来的两个后果，用之前得知道：

- 谁用你这个浏览器打开这个页面，谁就能看到密钥
- 浏览器扩展理论上能读到

所以：**别在公共电脑上用，别把带着密钥的页面截图发出去。**

## 群聊怎么运转

1. 点右上「群聊」
2. 点「成员」，加 2~4 个模型
3. 指定一个群主（群主不参与答题，只负责总结）
4. 提问

流程：第 1 轮各答各的 → 群主判断是否分歧 → 有分歧就第 2 轮互相反驳 → 群主给结论、理由、分歧点、保留意见。

## 头像

每个模型默认用预设的 emoji + 品牌色。想换成真图（比如自己画的二次元形象）：

1. 打开设置（右上 ⚙）
2. 单个改：点某个提供商那一行的「头像」，选一张图
3. 批量改：点「批量导入头像」，一次选多张，文件名里带 deepseek/qwen/kimi/glm/gpt/claude/gemini 会自动对应；对不上的会问你给谁

图会被压成 160×160 存在浏览器本地，**不会上传，也不占 token**。

## 群聊模板

常驻的组合可以存成模板：

1. 先把一个群聊的成员和群主配好
2. 点侧栏上方「模板」→「存当前群聊」，起个名字
3. 以后点「模板」里的「用这个」，直接开一个同成员的群聊

侧栏模型那一栏左边的小点：● 最近测通、✕ 最近失败、○ 还没测过。

## 插件

点右上「插件」，能装内置示例，也能从网址装。

插件长这样：

```js
export default function (api) {
  api.addCommand('hello', '打个招呼', () => {
    api.toast('你好');
  });
}
```

`api` 提供：`getState()`、`session()`、`toast(msg)`、`addCommand(id, title, fn)`。

完整的插件格式、清单写法和发布方法见 [PLUGINS.md](PLUGINS.md)。

**安全提醒**：插件跑在这个页面里，能看到页面的一切，包括 API 密钥。只装你看得懂代码的。

## 目录

```
index.html    界面骨架
styles.css    样式
app.js        全部逻辑（对话、群聊、插件）
server.mjs    本地静态服务器
```

零依赖，没有 npm 包，没有构建步骤，没有 CDN。

## 已知限制

- 花费是粗估，接口没返回 usage 时会偏
- 会话数据在浏览器里，换浏览器/清缓存就没了（可以先装「导出会话」插件存成文件）
- 浏览器直连各家接口，某些模型需要代理才能通
- 不支持工具调用（agent），当前只有纯对话
